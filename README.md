# VEGA: Линия огня

Браузерный бесконечный раннер-шутер: капитан Вега ведёт отряд сквозь заражённые зоны.

**Играть:** https://tamilamokrousova0.github.io/vega/

## Управление

- Мышь, палец или A / D — движение; огонь автоматический
- Пробел — перекат, Shift — щит, Q — ульта
- P — пауза, M — звук

## Локальный запуск

```bash
python3 serve.py
```

Затем открыть http://localhost:8765
